# VideoFeed

An Android application for discovering and watching videos from X (Twitter) profiles.

## Features

- Search X profiles by username.
- Browse videos from selected profiles.
- Infinite scrolling video feed.
- Built-in video player.
- Download videos.
- Simple and clean user interface.

## Technology

- Android
- Kotlin
- Gradle
